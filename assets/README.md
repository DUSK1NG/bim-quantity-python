# 教学素材说明

`assets/` 只允许存放已获授权、可用于课堂演示的 BIM 截图、界面截图和图标。素材应服务于本项目的教学说明，不作为真实工程交付物。

允许的内容：

- 已确认可公开或已取得书面授权的教学截图；
- 不含项目、人员或设备敏感信息的界面示意图；
- 已获授权的通用图标及其来源说明；
- 与 `docs/` 中相对仓库路径对应的版本化说明文件。

禁止的内容：

- 任何保密、受限、未授权或来源不明的 BIM 模型、图纸、导出表和截图；
- 含姓名、联系方式、账号、门牌、坐标、客户信息或其他个人信息的 BIM 数据；
- 可还原真实项目位置、造价、合同或安全信息的素材；
- 将样例或截图描述为真实项目结果。

提交素材前应确认授权范围、来源和去标识化状态，并在相邻说明中使用相对路径记录。样例数据是“程序演示数据”，不是一个真实项目。涉及金额的页面或截图必须保留原文声明：**本项目单价为教学示例数据，不用于正式工程造价。**
