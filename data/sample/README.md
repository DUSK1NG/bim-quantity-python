# 教学样例数据

本目录的 CSV 文件由 `scripts/generate_sample_data.py` 生成，用于检查标准字段、配置契约、质量异常和人工复核接口。它们是程序演示数据，不代表真实工程项目。单价不用于正式工程造价。

## 文件

- `sample_elements.csv`：固定种子生成的构件明细，使用 UTF-8-SIG 编码。标准列顺序遵循 `src.schema.STANDARD_COLUMNS`，并包含原始单位、行号、来源文件和异常追踪列。
- `sample_manual_validation.csv`：人工复核样例，保留 `auto_quantity` 和 `manual_quantity`，不覆盖自动计算结果。

生成器固定使用种子 `20260804` 和 240 行；人工复核文件从这些数据中抽取 12 行。按 [使用指南](../../docs/usage.md) 中的样例生成命令重建文件；脚本会报告生成文件的 SHA-256。

## 数据检查

样例包含缺失材料、缺失楼层、重复 GUID、零体积、名称异常、单位异常及无法匹配单价等情况。`exception_tags` 仅用于追踪演示样例，不能代替对 CSV 业务字段的检查。

本项目单价为教学示例数据，不用于正式工程造价。

请勿将样例、单价或人工抽查值用作真实工程数据、结算依据或正式造价成果。
